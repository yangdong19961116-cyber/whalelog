# dsh-pet 调研附件

这些文件是 2026-09-20 集成调研时留下的**证据与复现材料**，
配套文档是 `../dsh-pet-集成方案与调研.md`（结论、体积测算、实施计划都在那儿）。

## 里面是什么

| 文件 | 说明 |
|---|---|
| `sample_idle.webm` | 源素材样本：「待机呼吸休闲」动作，640×360 / 24fps / VP9-alpha，441 KB |
| `manifest.json` | 源素材的角色清单，内容只有一行 `{"body_box": [212, 60, 428, 330]}`（身体矩形，贴边锚点用） |
| `frame_01.png` | 用 ffmpeg 从上面那个 webm 解出的**第 1 帧**，RGBA 640×360，**alpha 完整**（255 级） |
| `test_cell.png` | 同一帧裁出角色、放大 2.247 倍、贴进鲸记 720×720 规范画布后的样子（体积实测件，361 KB） |

## 留着它们有什么用

**不用联网就能复现整条验证链**。下一轮开工时：

```bash
# 用仓库里这份样本重跑一遍解码，确认环境还通
python -c "import imageio_ffmpeg,subprocess; \
  subprocess.run([imageio_ffmpeg.get_ffmpeg_exe(),'-c:v','libvpx-vp9','-i',\
  'docs/dsh-pet-调研附件/sample_idle.webm','-frames:v','1','-pix_fmt','rgba','/tmp/check.png'])"
```

解出来的 PNG 应该和 `frame_01.png` 一致（alpha 有 255 级、透明占比 82.9%）。
**如果 alpha 全是 255，说明解码路径又走回 PyAV 了**——那是已知的坑，
原因与正确写法见主文档第 4 节。

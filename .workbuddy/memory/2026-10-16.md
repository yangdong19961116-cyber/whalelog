# 2026-10-16

## 托盘菜单加「播放动画…」自选播放（用户：「菜单里加一个可以自选播放动画的功能，注意集成到二级菜单不要全部显示在一级菜单里」）

带托盘菜单截图来的一条需求。一级菜单只多一项 `播放动画…  ▸`，点开是二级页。

### 先量了素材，做法是被数据逼出来的

在真素材里数了一遍：`assets/characters/dsh/anim` 共 **106 个动作，其中 93 个是 ambient**
（`clickBounce` 5、`move` 3、`turn`/`idle`/`drag`/`cheer`/`archive` 各 1）。
93 个 ambient 的名字还几乎全不重复（「吃汤圆」「写代码」「余额-分文不剩」…），
按第二段再分也只有「余额」(6)「工作状态」(4) 两组有意义。
→ **光靠分组压不短，二级页必须有搜索框。** 这一条决定了整个设计。

### 设计决策

- **二级页不是新窗口，是同一个窗口换一屏内容**。`TrayMenuWindow` 失焦即关
  （`OnDeactivated` → `RequestClose`），真弹子窗口的话，子窗口拿到焦点的瞬间
  父菜单就会把自己关掉。
- **搜索框排在列表上面**（先加的就在上面）。这块列表一百多项，搜索框跟在后头等于没有。
- **选中动作时自动打开**桌面小鲸鱼 / 动画开关：用户点的是"播放动画"，
  不是"研究两个开关怎么配合"。
- **动作名显示短名**（去掉角色前缀，分组标题已经说过一遍）；前缀认不出角色时原样显示。
- 一级菜单保留原样，只多一项 —— 这条是用户明确要求的。

### 新增 / 改动

- 新增 `Services/AnimMenu.cs`：`Build(lib, keyword)` 把素材库变成"二级页行清单"的**纯函数**
  （`AnimMenuRow{Kind, Text, Action}`）。抽出来是为了能测 —— 菜单是代码构造的 WPF 控件、
  喂不进断言，而"列哪些行、叫什么名字、怎么分组"才是真会写错的地方。
  **`selftest.csproj` 的 `<Compile Include>` 已同步加上**。
- `AnimSheet.cs`（`AnimActions`）：`DisplayName(role)` 角色中文名、`ShortName(action, role)` 去前缀。
- `AnimLibrary.cs`：`GroupedActions()`（按 `AnimActions.All` 顺序、空组不出现、未分类排最后）
  + `Search(keyword)`（匹配动作名或角色中文名）。
- `TrayMenuWindow`：`AddNavItem`（点了不关菜单的导航项）、`AddHeader`、`AddSection`
  （可反复重填的区域）、`AddSearchBox`（叠一层灰字占位，TextBox 没有原生 placeholder）、
  `ClearItems`、`Relayout`（换页后重新收进工作区）、`RowTextsForProbe`（探测用，**必须递归**
  展开嵌套面板，否则那块列表一行都读不到）。XAML 加了 `ScrollViewer MaxHeight=560`。
- `FloatingWindow`：`Animations` / `PlayAction(action)`。
- `App.xaml.cs`：`ShowTrayMenu` 拆出 `BuildMainMenu`（给二级页的「返回」复用）+
  `BuildAnimationMenu(menu, x, y, library = null)` + `PlayChosenAction`。
- 新增出图开关 `--shot-anim-menu [png]`：一级页和二级页各出一张
  （素材挑"第一个真有 anim 的形象包"，免得拍到空菜单）。
- 文档：README（菜单说明 + 开关列表）、HANDOFF（版本沿革加一条）。

### 踩到的坑

- ⚠️ **看图才发现：搜索框最初被排在动作列表下面**（一百多项之后）。
  探针只断言"有没有搜索框"，照样过；界面上得滚到底才看得见。
  → 已改成先加搜索框，并补了一条**顺序**断言（"搜索框在第 2 行，第一个动作在第 5 行"）。
  **"有没有"和"在哪儿"是两回事，能出图的时候一定要出图。**
- ⚠️ `WriteProbeAnimation` 里的 anchor(360,660) / characterHeight(600) 是**给 720 画布写的**，
  我拿 `frameSize=8` 去配，帧表校验直接判掉 → 探针素材扫到 0 个动作。
  探针自造素材时帧尺寸要跟着那套常量走。
- ⚠️ 编译 `CS0165 使用了未赋值的局部变量 section`：`Fill` 被当作回调传给 `AddSearchBox`，
  编译器无法证明调用时 `section` 已赋值 → 改成 `TrayMenuWindow.Section? section = null` +
  `if (section is not { } host) return;`。
- `--selfcheck` 的日志落在 **`WHALELOG_DATA_DIR`** 下（`AppPaths.LogDir = Root\logs`），
  不是 `%APPDATA%\WhaleLog\logs` —— 设了隔离数据目录就要去那边找日志。
- 自检环境里形象包解析成**原版**（没有 anim 目录），所以探针必须自己造素材，
  拿真实素材验的只是"没扫到"那条分支。

## dsh-pet 集成调研（未改主程序）

用户提出把 `MerZlin/dsh-pet-indesktop` 的动画素材与桌宠交互接进鲸记。
本轮只做可行性验证与方案，产出：

- `docs/dsh-pet-集成方案与调研.md` —— 完整方案（结论 / 许可 / 规格 / 体积 / 实施顺序 / 待决策）
- `docs/dsh-pet-调研附件/` —— 样本 webm + manifest + 解帧 PNG + 体积实测件（不联网可复现）

### 技术结论（全部实跑）

- 源素材：640×360 / 24fps / **VP9-alpha 透明 webm**，106 个，共 52 MB，角色仅 213×267。
  源自 `PC2005-cloud/dsh-pet`；本项目是 PySide6 桌面应用，代码 MIT。
- 鲸记只吃 **720×720 精灵图 PNG**（`docs/动态素材规格.md` 第 6 节实测否掉了 GIF/APNG/WebP）。
- 转码链：ffmpeg 解 RGBA 帧 → 裁角色 → 放大 2.247× → 贴 720×720（中心 x=360、脚底 y=660）。
- 体积：全量 106 个 ≈ **1.4 GB**（便携包现在才 58 MB）；精简 8 个 ≈ 110 MB；抽到 12fps 再减半。

### ⚠️ 两个必须记住的坑

1. **PyAV 会静默丢 alpha。** `av` 解这个 webm 得到 `yuv420p`、alpha 全 255，
   而文件 stream metadata 里明明有 `ALPHA_MODE=1`。`to_ndarray('rgba')`/`'bgra'` 都无济于事，
   `'yuva420p'` 直接报 `Conversion ... is not yet supported`。
   → **取 alpha 只能走 `imageio-ffmpeg` 自带的 ffmpeg 二进制**（本机没有系统 ffmpeg，
   但那个包里的 7.1 含 libvpx，实测能解出 256 级 alpha）。
2. 源项目的 Release 资产（140~270 MB 的 exe/zip）是**打包好的应用，不是素材源**；
   素材要去源码仓库的 `assets/characters/shenshen/videos/` 拿。

### 许可硬约束

素材是 CC BY-NC-SA 类同人素材（OC「溟月」/ 画师上善无形），**仅限个人非商业使用，必须署名**。
鲸记自用没问题；一旦要发布或商用，这批素材及由其生成的动画必须整体撤下。

### 交互模块

PySide6/Python 代码不能直接搬，能搬的是行为参数（`pet/catalog.py` 里：动画链概率、
移动距离 60~240px、拖拽阈值 5px、缩放档位等）。真正值得新增的能力是**「自主走动 + 贴边」**——
鲸记目前完全没有。菜单/设置/IPC/余额事件都不在范围内。

### 待用户决策

许可是否接受 / 体积档位 / 是否抽帧到 12fps / 形象替换还是共存 / 要不要做自主走动。

## dsh-pet 落地（同一天紧接着做完，1.3.2 → **1.4.0**）

用户在 5 个点上拍板：**接受许可**（个人非商业 + 界面署名）、**所有素材都要不精简**、
**形象替换成新的但给旧版留切换开关**、**不做自主走动**、**但要贴边**。

### 路线改了：不转精灵图，改成运行时解码

调研时算的是「全量转 720×720 精灵图 ≈ 1.4 GB」。真做的时候换成
**透明 webm 原样搬运 + 运行时 ffmpeg 逐帧解**：

| | 结果 |
|---|---|
| 素材包 | 106 动作 / 25423 帧 / **51.9 MB**（原样搬运，零重编码，画质与源素材一致） |
| 解码开销 | 解 241 帧 0.38 s；边解边放 142 MB 内存峰值；起一次 ffmpeg ≈ **150 ms** |
| 便携包 | 58 MB → **139.6 MB**（+52 MB 素材 +84 MB ffmpeg.exe，两者都压不动） |

关键设计（都写在 `Services/VideoDecoder.cs` 的注释里）：
**8 帧环形缓冲**（满则阻塞生产者 → 天然不积压、几乎不吃 CPU）、
**鼠标移入悬浮窗就预热**（`SpritePlayer.Warm`，抵掉 150 ms 冷启动）、
**时间驱动取帧、一个 tick 最多贴一帧、落后逐帧追但绝不快进**。

### 形象包

`Assets\characters\<形象ID>\` 一套形象一个目录；`classic` 是保留名，根目录就是 `Assets\` 本身
（**原版没搬家**，老用户往 `Assets\` 放过的图照样有效）。
`CharacterPacks.Resolve` 降级顺序 **设置里那个 → dsh → classic**（原版是嵌入资源、永远能用）。

### 贴边

吸附改成**两轴独立判定**（能吸到角上），关掉吸附也记方向。**按用户决定没做自主走动。**

### 两个新踩的坑

1. **`AnimSheet.ValidateFilter` 把分隔符认错**：先按 `:` 切会把 `crop=384:360:128:0` 的
   **滤镜名**切成 `crop=384` → **106 个动作全被拒收**，界面表现只是"动画一个都不出来"。
   正确顺序是**先按 `=` 切名字、再按 `:` 切参数**，位置参数只放行数字、具名参数走白名单。
   这个 bug 是自测抓出来的。
2. **打包脚本的"暂存目录"会被异步回收**（最坑的一个）：
   受限环境拦「一次删 50+ 文件」并要人工确认，**被拦下的删除请求会在后台被逐个补执行** ——
   打包期间它把暂存树里的 `Assets\` 以约 **17 个/秒**匀速啃掉，
   于是包变成**「程序在、素材没了」**，而脚本自己**一句报错都没有**。
   定位方式：脚本里加采样线程看到 465 → 244 匀速下降；同时发现
   `build\asset-probe-data` 从 841 个文件被削到 3 个，才确认是那个机制。
   → **改成不落暂存目录**（生成的两份 json 用 `writestr`，出厂素材导到系统临时目录，
   形象素材直接读源目录进 zip），并且**落盘后回查关键条目**，缺一条就非 0 退出。

### 顺带修正的一处认知

`dotnet restore` 报 `Value cannot be null (Parameter 'path1')` 一直被认为是"受限会话做不到"，
真因只是 **shell 拿不到 Windows 会话的环境变量**（`ProgramData` / `APPDATA` 缺失）。
写成正式工具 `tools/mkenv.py`（读注册表导出 `.tmp-env.sh`），`source` 之后
`dotnet build -c Release` **0 错 0 警**，根本用不上那套 offline_restore。

## 补丁：用户报「设置里点新形象没有反应」（同一天下午，1.4.0 → **1.4.1**）

**根因不是代码**：形象按钮是按"程序旁边实际有哪些形象包"动态生成的，而**只有打包脚本**
会把 `assets\characters\` 放进便携包，`WhaleLog.csproj` 从来没把它拷进编译产物。
用户从 `src\WhaleLog\bin\Release\net8.0-windows\` 直接跑（桌面快捷方式指的就是这儿），
那一排里「溟月」是灰的、写着「（缺素材）」，**点上去毫无反应**；说明行当时只在讲原版形象。

**改了三处**：
1. `WhaleLog.csproj` 加 `Content Include="..\..\assets\characters\**\*"` + `Link` + `PreserveNewest`
   → 开发构建与出厂包同一套素材布局。
2. `MainWindow.xaml.cs`：缺素材的**原因写进说明行**（原来只在 ToolTip 里）。
3. `DiagnosticsService.cs`：自检「形象包」节先列出**真实素材目录**的 `[有]/[缺]`；
   新增 `ProbeCharacterChipsPage` —— 真起设置页，断言按钮可点 / 点了设置跟着改 / 双向 / 缺素材时禁用且写明原因。
   顺带给 `App.xaml.cs` 加了 `--shot-settings`。

**自检 187 → 195 项**（21 段不变；有另一个实例在跑时 194）。

**这一轮的三条教训**（已写进 MEMORY.md「探针/自检纪律」）：
1. 界面层要断言「**这个控件点得动吗**」，不能只断言「背后的函数返回对吗」——
   纯逻辑那 13 条全过，问题照样发生。
2. **点一个已经选中的 RadioButton 不会重抛 `Checked`**（true→true 无变化）。
   第一版断言就栽在这里，测出来的是假失败。
3. **脚本里跑 `--selfcheck` 必须带 `--quiet`**，否则弹「自检完成」对话框等人点，
   在 agent/批处理里表现为卡死到超时（日志其实早写完了）。

**给用户的即时处置**：把 `assets\characters` 拷进那个输出目录（已完成），重启小鲸鱼即可。
